## [0.1.0] - 2026-08-30

### Aggiunto

- Prima release desktop per macOS e Windows.
- Server SQLite/LAN incorporato, renderer Next.js e shell Electron.
- Setup lega, lobby con QR, asta live, rose, crediti, svincoli, backup e ripristino.
- Accessibilità, target touch e comportamento responsive condivisi tra web e desktop.
- Pipeline CI, checksum degli installer e documentazione pubblica del prodotto.
